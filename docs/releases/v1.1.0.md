# PowerLeitstand PRO v1.1.0 · Windows

## Deutsch

PowerLeitstand PRO ist die weiterentwickelte Windows-WPF-Version. Der bisherige Projektname Power Control PRO wird durch PowerLeitstand PRO ersetzt. Die portable Windows-x64-Datei heißt jetzt `PowerLeitstand-PRO.exe` und benötigt keine separate .NET-Installation.

### Neu und verbessert

- Lokale Windows-Benutzer lassen sich erstellen, bearbeiten, umbenennen, deaktivieren und löschen. Kennwörter können gesetzt oder entfernt werden; geschützte Konten und das letzte aktive Administratorkonto werden bei kritischen Aktionen berücksichtigt.
- Die App zeigt Administratorrechte deutlicher an und bietet eine verständlichere Anforderung erhöhter Rechte. Benutzer-, Optionen- und Bestätigungsfenster wurden im Stil der Hauptansicht überarbeitet.
- Der Timer unterstützt Herunterfahren, Neustart und Windows-Sperre. Tray-Betrieb, Autostart und Warn- beziehungsweise Bestätigungstöne wurden verbessert.
- DISM und SFC zeigen Fortschritt und Ergebniszusammenfassungen. Der Reparaturbefehl ist kopierbar; Ereignis- und Reparaturprotokolle sind besser strukturiert. Die Protokollordner lassen sich direkt öffnen.
- Eine neue Update-Anzeige prüft GitHub-Releases. Die Installation eines Updates erfolgt erst nach Zustimmung und SHA-256-Prüfung der einzigen EXE im Release; bei keiner oder mehreren EXEs wird nicht automatisch aktualisiert.
- Status- und Log-Bereiche, Icons, Schriften und Abstände wurden über die Seiten und Designs hinweg vereinheitlicht.

### Hinweise

Windows-Reparaturen und Änderungen an lokalen Benutzern benötigen Administratorrechte. Das Entfernen eines Kennworts entfernt keine Windows-Hello-PIN. Einstellungen und Protokolle bleiben aus Kompatibilitätsgründen unter `%LOCALAPPDATA%\Power Control PRO` gespeichert. Die EXE ist derzeit nicht digital signiert. Vor dem Start die SHA-256-Prüfsumme mit `SHA256SUMS.txt` abgleichen.

## English

PowerLeitstand PRO is the updated Windows WPF application. The former Power Control PRO project name has been replaced with PowerLeitstand PRO. The portable Windows x64 file is now named `PowerLeitstand-PRO.exe` and requires no separate .NET installation.

### New and improved

- Create, edit, rename, disable, and delete local Windows users. Passwords can be set or removed; protected accounts and the last active administrator are safeguarded during critical actions.
- Administrator status and elevation requests are clearer. User, options, and confirmation dialogs now better match the main interface.
- The timer supports shutdown, restart, and Windows lock. Tray behavior, startup with Windows, and warning or confirmation sounds have been improved.
- DISM and SFC display progress and result summaries. Repair commands can be copied; event and repair logs are more structured, with direct access to their folders.
- A new update indicator checks GitHub releases. Updates are installed only after consent and SHA-256 verification of the release's sole EXE; no automatic update occurs if there are zero or multiple EXEs.
- Status and log areas, icons, typography, and spacing are more consistent across pages and themes.

### Notes

Windows repairs and local-user changes require administrator rights. Removing a password does not remove a Windows Hello PIN. For compatibility, settings and logs remain in `%LOCALAPPDATA%\Power Control PRO`. The EXE is currently unsigned. Verify its SHA-256 checksum against `SHA256SUMS.txt` before running it.
